# Product

## Register

product

## Users

MyAgent is for developers working inside local code projects. They need a focused place to discuss a task, inspect project context, and eventually let an agent plan and act without losing the thread between sessions.

## Product Purpose

Provide a calm, trustworthy agent workbench built around workspaces and persistent conversations. The key interaction is bringing selected code or files into a conversation, asking a focused question, and keeping the resulting context available as the task evolves.

## Brand Personality

Calm, professional, focused. The interface should feel precise and dependable without becoming sterile.

## Anti-references

- Decorative AI dashboards with glowing gradients, glass panels, or sci-fi chrome.
- Card-heavy SaaS layouts that fragment one continuous working surface.
- Consumer-chat bubbles and oversized avatars that make technical work feel casual.
- Visual noise that competes with code, reasoning, or the current task.

## Design Principles

- Keep the current task visually dominant; navigation and system controls should stay quiet.
- Make project context visible and easy to verify before an agent acts.
- Prefer familiar desktop-tool patterns over invented interaction models.
- Use color to communicate selection, focus, and state rather than decoration.
- Preserve continuity so another agent or a later session can resume without guessing.

## Accessibility & Inclusion

Target WCAG 2.2 AA. All essential interactions must be keyboard accessible, focus-visible, usable without color alone, and respectful of reduced-motion preferences. Light and dark themes must retain readable contrast.
